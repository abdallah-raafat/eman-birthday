# Happy Birthday Eman 🩵 — 1st of October

A romantic, flirty, and modern birthday web application created with all my heart by **دودك وميشو (Abdallah)** for **مونمونتي وميمي (Eman)**.

- **Birthday Date**: October 1st (1 أكتوبر)
- **Live URL**: https://abdallah-raafat.github.io/eman-birthday/
- **Soundtrack**: Mahmoud El Esseily - "كل سنة وأنت قلبي، كل سنة وأنت جنبي" (Full song, automatic loop)

## ✨ Modern Highlights & Features
1. **Interactive Romantic Mini-Games (6 Games)**:
   - 💙 **لقط القلوب (Heart Catcher)**: High-speed canvas arcade catching baby blue hearts, stars, and love letters.
   - 🧠 **ذاكرة الحب (Love Memory)**: 3D flip card memory matching personal photos, rings, cakes, and crowns.
   - 🎈 **فرقع البالونات (Balloon Rush)**: 30-second reflex balloon popping with physics sway and floating combos.
   - ⚡ **سرعة نبضك (Pulse Reflex)**: Millisecond precision reaction timer measuring pulse speed.
   - 🎂 **ابني التورتة (Cake Stacker)**: Slice-physics cake tower building.
   - 💌 **تعرف عني إيه؟ (Romantic Trivia Quiz)**: Timed questions about our shared memories with speed bonuses.

2. **🏆 Synced Challenge Board (عبدالله ضد إيمان)**:
   - Real-time cross-device score synchronization via MQTT broker.
   - Live head-to-head versus statistics, leading crowns, and records breakdown.
   - 15 sweet romantic achievements to unlock.
   - Live activity feed & rival broken-record alerts.

3. **✨ Discover Tab (اكتشفي الأسرار)**:
   - 🎡 **عجلة الحب (Love Wheel)**: Physics spinning wheel with romantic dates, surprises, and promises.
   - 🎟️ **كوبونات الحب (Scratch Coupons)**: Interactive lottery-style scratch cards with redeemable romantic coupons.
   - 💌 **افتحي لما… (Open When Envelopes)**: Interactive sealed letters for every mood and late night.
   - 🔐 **كلمة السر السحرية (Secret Passwords)**: Guess the nickname to unlock hidden love messages.
   - 🌙 **الأسرار المستخبية (Easter Eggs)**: Discover 7 hidden surprises across the website.

4. **💎 Visuals & Styling**:
   - Radiant Baby Blue & Labani glassmorphic theme.
   - Responsive touch and mobile layout with native safe area insets.
   - Web Audio API synthesizer for sound effects.
